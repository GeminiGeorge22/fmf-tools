# Install FMF Tools MCP servers

These are hosted Streamable HTTP MCP servers. Do not run a local process.

1. Start with the directory: `https://tools.fmf-x402.workers.dev/mcp`
2. In Cline, Cursor, Claude, or VS Code, add a custom MCP connector and paste that URL.
3. Authentication: none. `tools/list` is free. `tools/call` is pay-per-call.
4. The full catalog is at https://tools.fmf-x402.workers.dev/?ref=github
