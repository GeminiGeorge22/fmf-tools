# Install FMF Tools MCP servers

These are hosted Streamable HTTP MCP servers. Do not run a local process.

1. In Cline, open MCP / Connectors and add a custom connector.
2. Paste one of the MCP URLs from the README, for example `https://mtg-sim.fmf-x402.workers.dev/mcp`.
3. Authentication: none. `tools/list` and the documented free tools need no account.
4. Paid tools/call settle with MPP on Tempo or x402 on Base when the client supports it.

Full server list and URLs: see README.md.
